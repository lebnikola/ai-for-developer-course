# Мини-анкета — домашнее задание

**Тема**: Изучение возможностей ИИ для генерации кода

---

## Цель задания

Необходимо создать простое full-stack приложение "Мини-анкета", в котором есть анкета с фиксированным количеством вопросов. Пользователь отвечает на вопросы анкеты и эти ответы сохраняются в памяти приложения.

---

## Требуемый функционал

### Backend (API)

- **GET /questions** — возвращается список вопросов анкеты (жестко заданы на backend)
- **POST /answers** — принимает ответы пользователя с frontend и сохраняет их в памяти приложения (персистентность не требуется)
- **GET /answers/stats** — возвращает общую статистику по анкетам (всего анкет/ всего ответов)

### Frontend

- Загружает вопросы с backend по API `/questions`
- Отображает их в HTML/JS интерфейсе
- Отправляет ответы на backend по API `/answers`
- Отображает статус отправки пользователю в виде всплывающего окна: "Спасибо" или "Ошибка отправки"

---

## Технологический стек

- **Backend**: Python + FastAPI
- **Frontend**: React (CDN), HTML (single-file), JavaScript
- **Тестирование**: pytest
- **Зависимости**: uv

---

## Дополнительные уточнения к задаче

- **Вопросы анкеты**: 5 вопросов на тему "Мои домашние питомцы" (шаблон в JSON)
- **Счётчики**: frontend обновляет статистику каждые 15 секунд, цифры показывают количество отправленных анкет и только заполненных (не пустых) ответов
- **Инструкция по запуску**: в readme.md должна быть информация с порядком действий для запуска на разных ОС (Windows/Linux/Mac)
